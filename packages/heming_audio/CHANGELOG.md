# 变更记录

此文件记录仓库内 `heming_audio` 包的能力。包版本与主应用版本独立，应用发布记录见 [项目变更记录](../../CHANGELOG.md)。

## 0.0.1

- 增加 Windows WASAPI / Android AAudio 输出、五秒有界 PCM 缓冲和预约播放。
- 增加原生 TCP 音频传输、UDP 校时、硬件时钟估计与漂移修正。
- 增加媒体检测、完整解码校验、规范 FLAC 转换、进度及取消清理。
- 增加本机音量、声道、静音及输出延迟补偿 API。
- 增加独立流式试听，支持暂停、继续、定位、停止及自然结束排空。
- 补充传输分帧、时钟、呈现时序和试听测试；合并音频块响应并启用 TCP_NODELAY，减少小包延迟确认等待。

平台支持、API 边界和测试方式见 [README](README.md)。
