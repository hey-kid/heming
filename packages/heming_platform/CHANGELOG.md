# 变更记录

此文件记录仓库内 `heming_platform` 包的能力。包版本与主应用版本独立，应用发布记录见 [项目变更记录](../../CHANGELOG.md)。

## 0.0.1

- 增加 Windows / Android 系统中断事件和可取消的系统音轨提取。
- 增加 Android 同步播放与本机试听的独立焦点管理及保守恢复机制。
- 增加 Android 媒体前台服务、播放期运行锁和系统媒体状态镜像。
- 增加通知停止操作，并通过激活代次隔离旧通知与新任务。
- 增加 Windows 播放期电源请求，允许关屏和锁屏，保留真实休眠及输出变化通知。

平台差异、生命周期和验证范围见 [README](README.md)。
