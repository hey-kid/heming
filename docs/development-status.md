# 项目状态与路线图

更新于 2026-11-12，对应 Windows / Android **1.5.0+10**。

和鸣已具备完整的局域网组队、资源管理和音频播放链路。当前重点是扩大设备覆盖、验证长时间运行和测量实际出声同步精度。本文区分功能实现、已执行验证与后续计划；版本变化见 [更新日志](../CHANGELOG.md)。

## 平台状态

| 平台 | 当前状态 | 验证范围 |
| --- | --- | --- |
| Windows x64 | 可构建、运行和打包为便携目录 | 已验证实际安装包启动、组队、播放、试听、桌面布局和主题设置 |
| Android | 最低 Android 8.0 / API 26，构建 ARM32 与 ARM64 APK | 已在一款 Android 10 / API 29 手机验证；不代表所有系统和厂商设备 |
| iPhone / iPad / Mac | 尚未实现平台适配 | 等具备 Mac 编译与真机验证环境后推进 |

当前 Android 安装包仍使用开发签名，Windows 尚无独立安装器和自动更新机制。

## 已实现功能

| 领域 | 当前能力 |
| --- | --- |
| 设备组队 | 局域网自动发现、手动地址加入、主控审批；每组最多六台，包含主控 |
| 角色控制 | 两种平台均可作为主控；组内申请接管、明确移交、停止并清理旧任务 |
| 同步播放 | 约五秒 PCM 应用缓冲、共同开始时间、周期校时与播放漂移修正 |
| 播放队列 | 完整主从队列、上一首 / 下一首、点选切歌；顺序 / 随机从下一首生效 |
| 资源库 | 原格式导入、规格检测、显式转换、单层分组、批量移动和组内排序 |
| 本机试听 | 未组队时临时播放，支持暂停、继续和拖动；与同步队列隔离 |
| 本机输出 | 独立音量、静音、左 / 右 / 完整音轨 |
| 后台播放 | Android 播放前台服务及运行锁；Windows 播放期电源请求 |
| 系统媒体状态 | Android 通知与媒体会话显示曲名、进度和状态，提供停止及返回应用入口 |
| 音频焦点 | 临时降音或静音时保持任务时间轴；条件允许时恢复，无法可靠识别时提供手动恢复 |
| 界面 | 桌面自适应分栏、移动端底部导航、明暗模式、六种可保存的主题色 |

完整交互规则见 [产品规格](v1-spec.md)，实现结构见 [架构说明](architecture.md)。

## 当前验证基线

1.5.0 的 Flutter / 平台自动测试 **142 项通过**，覆盖会话、资源、试听、界面与偏好等用例。六种主题色的主要文字和按钮配对在浅深模式中均检查了至少 4.5:1 的对比度。随后仅更新测试中的语义查询 API，定向复查设置测试 **3 项通过**，不重复计入 142 项。静态分析未报告问题。

Windows Release 和 Android ARM32 / ARM64 Release 均完成构建。Android APK 的必要原生库、架构和签名已检查，实际覆盖安装包与构建产物一致；Windows 便携目录与解压产物逐一核对。两端实际验证了主题切换、明暗模式独立保存及重启保留。

1.5.0 的实际设备检查以界面和偏好为主，没有重新执行长时网络或声学测量。历史版本的播放、传输、后台与焦点结果及其边界，见 [设备验证摘要](physical-device-validation.md)。运行方法见 [构建与测试](build-and-test.md)。

## 已知边界

- **尚未测得扬声器的同步精度。** 约 5 ms 是研究目标，进度一致、缓冲充足或软件时钟接近都不能代替声学测量。
- **六台是逻辑上限。** 四台、六台混合硬件的持续播放能力尚未验收。
- 后台、熄屏和音频焦点处理尚未覆盖多厂商 Android、新系统限制、真实来电、蓝牙、输出热插拔和 Windows 锁屏 / 休眠恢复的完整组合。
- 已向 Android 系统提供媒体会话和通知；锁屏卡片的实际样式及操作仍需对应设备验证。
- 同步播放不提供暂停续播、拖动进度、无缝连播或交叉淡入淡出；这些限制不适用于未组队的本机试听。
- 输入格式覆盖取决于内置解码器及平台媒体能力。应用未内嵌 FFmpeg；转换生成的 FLAC 使用 verbatim 子帧，体积接近未压缩 PCM。
- 原生层提供延迟补偿工程接口，但没有面向用户的完整标定工具和校准数据。
- 正式发行签名、安装更新流程及干净系统上的分发验证仍待完善。

## 后续优先级

| 优先级 | 工作 | 预期产出 |
| --- | --- | --- |
| 1 | 两台设备的启动偏差与长期漂移测量 | 固定设备 / 输出路径的录音或回环报告 |
| 2 | 当前 Release 的双向持续播放、多机容量与弱网回归 | 可复现的设备矩阵、错误和缓冲记录 |
| 3 | 扩展后台、焦点和输出变化场景 | 按系统、机型及事件分类的兼容性结果 |
| 4 | 完善签名、安装和升级流程 | 可验证、可保留用户资源的发行流程 |
| 后续 | Apple 平台适配 | 在 Mac 环境中完成原生实现、构建与真机验证 |

这些是工作方向，不是已交付功能或日期承诺。具体用例和记录要求见 [验证计划](prototype-plan.md)。
