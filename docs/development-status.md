# 项目状态与路线图

更新于 2026-11-13，对应 Windows / Android 源码 **1.6.1+15**。

和鸣已具备完整的局域网组队、资源管理和音频播放链路。当前重点是扩大设备覆盖、验证长时间运行和测量实际出声同步精度。本文区分功能实现、已执行验证与后续计划；版本变化见 [更新日志](../CHANGELOG.md)。

## 平台状态

| 平台 | 当前状态 | 验证范围 |
| --- | --- | --- |
| Windows x64 | 可构建、运行和打包为便携目录 | 1.6.1 Release ZIP 构建、原生扫描与试听集成通过；独立 debug 入口完成试听界面和文件夹定位检查 |
| Android | 最低 Android 8.0 / API 26，已构建 ARM32 与 ARM64 APK | 1.6.1 正常 Release 在 Android 10 / API 29 ARM32 手机完成安装、启动及短时扫描试听；独立 debug 另验证原生链路，不代表旧版数据升级或所有机型 |
| iPhone / iPad / Mac | 尚未实现平台适配 | 等具备 Mac 编译与真机验证环境后推进 |

当前 Android 安装包仍使用开发签名，Windows 尚无独立安装器和自动更新机制。

## 已实现功能

| 领域 | 当前能力 |
| --- | --- |
| 设备组队 | 局域网自动发现、手动地址加入、主控审批；每组最多六台，包含主控 |
| 角色控制 | 两种平台均可作为主控；组内申请接管、明确移交、停止并清理旧任务 |
| 同步播放 | 约五秒 PCM 应用缓冲、共同开始时间、周期校时与播放漂移修正 |
| 播放队列 | 完整主从队列、上一首 / 下一首、点选切歌；顺序 / 随机从下一首生效 |
| 资源库 | 原格式导入、规格检测、显式转换、单层分组、批量移动和组内排序 |
| 本机扫描 | Windows 默认及指定目录、Android 已授权媒体库；分类搜索、多选反选、分组添加、独立复制及扫描入库内容去重 |
| 本机试听 | 未组队时临时播放，支持暂停、继续和拖动；与同步队列隔离 |
| 扫描预览 | 扫描列表在入库前试听音频，底部播放条支持暂停、定位和关闭；临时预览不改变勾选或资源库，视频不做内置解析 |
| 来源操作 | 扫描来源可交给系统播放器打开；Windows 支持在文件夹中显示，作为内置试听以外的入口 |
| 本机输出 | 独立音量、静音、左 / 右 / 完整音轨 |
| 后台播放 | Android 播放前台服务及运行锁；Windows 播放期电源请求 |
| 系统媒体状态 | Android 通知与媒体会话显示曲名、进度和状态，提供停止及返回应用入口 |
| 音频焦点 | 临时降音或静音时保持任务时间轴；条件允许时恢复，无法可靠识别时提供手动恢复 |
| 界面 | 桌面自适应分栏、移动端底部导航、明暗模式、六种可保存的主题色 |

完整交互规则见 [产品规格](v1-spec.md)，实现结构见 [架构说明](architecture.md)。

## 当前验证基线

### 1.6.1+15

Flutter / 平台自动测试 **192 项通过**，全项目静态分析未报告问题。新增回归覆盖扫描试听、异步准备与快速切换、共享停止和缓存释放、试听与勾选隔离，以及外部打开的平台调用和界面状态。

Windows 原生扫描集成已重跑通过；Android 10 ARM32 手机上的独立 `scancheck` debug 包也完成同项集成。两端均在入库前验证播放、暂停、定位、继续和停止，确认试听期间资源库仍为空；后续原有的入库、独立副本和去重断言继续通过。原生集成与上述 192 项分开记录，使用合成静音素材，不是声学测量。

Windows 1.6.1+15 Release ZIP 已构建，便携目录已更新并核对 EXE 版本。Windows 独立 debug 视觉入口只显示两项合成素材，实际点击音频后出现底部播放条、进度及暂停图标；关闭后播放条消失，已选数量保持为零。更多菜单的文件夹定位成功打开测试目录并选中合成 WAV。本轮 Windows 新界面的实际操作来自该 debug 入口，没有记作正常 Release 界面验收。

Android 10 独立 `scancheck` 视觉入口显示正常推进的音频播放条，视频没有内置试听按钮；关闭后播放条消失且临时试听缓存目录已清理，已选数量仍为零。外部打开经系统选择器交给华为音乐，实际显示并播放合成 WAV，返回后扫描页仍无选择及内置试听。

Android 1.6.1+15 正常 Release 使用 `lib/main.dart` 入口及产品包名，ARM32 / ARM64 架构、原生库、版本、标签和 APK v2 签名检查通过。该包已安装到 Android 10 ARM32 手机并核对版本；正常启动后，从空资源库进入添加、扫描及授权，再点击合成 WAV，出现底部 0:00 / 0:20 播放条和暂停图标，已选为零，返回资源库仍为空。本轮开始检查时手机未安装产品包，因此记录为正常安装、启动及短时试听流程，不是旧实验版数据覆盖升级验收。

Windows 外部播放器实际打开、Windows 正常 Release 新界面操作，以及 Android 14 真机仍未验证。本轮没有声学测量或长时间同步播放回归；详细结果见 [设备验证摘要](physical-device-validation.md)。

## 已知边界

- **尚未测得扬声器的同步精度。** 约 5 ms 是研究目标，进度一致、缓冲充足或软件时钟接近都不能代替声学测量。
- **六台是逻辑上限。** 四台、六台混合硬件的持续播放能力尚未验收。
- 后台、熄屏和音频焦点处理尚未覆盖多厂商 Android、新系统限制、真实来电、蓝牙、输出热插拔和 Windows 锁屏 / 休眠恢复的完整组合。
- 已向 Android 系统提供媒体会话和通知；锁屏卡片的实际样式及操作仍需对应设备验证。
- Android 14 及以上部分媒体授权尚无真机验收；当前 Android Release 已完成正常安装和短时扫描试听，旧版数据覆盖升级与完整扫描导入流程仍需另行验证。
- 扫描内置试听沿用现有音频解码能力，支持 WAV、MP3、FLAC；其他格式可尝试系统播放器。视频没有内置画面或音轨预览，外部播放器的兼容性由设备上的应用决定。
- 同步播放不提供暂停续播、拖动进度、无缝连播或交叉淡入淡出；这些限制不适用于未组队的本机试听。
- 输入格式覆盖取决于内置解码器及平台媒体能力。应用未内嵌 FFmpeg；转换生成的 FLAC 使用 verbatim 子帧，体积接近未压缩 PCM。
- 原生层提供延迟补偿工程接口，但没有面向用户的完整标定工具和校准数据。
- 正式发行签名、安装更新流程及干净系统上的分发验证仍待完善。
